# Source des données Ciqual

Le fichier `ciqual-2025-foods.csv` est un extrait déterministe de :

> Anses. 2025. Table de composition nutritionnelle des aliments Ciqual.

- version source : 2025-11-03, publiée le 19 novembre 2025 ;
- DOI du jeu de données : https://doi.org/10.57745/RDMHWY ;
- fichier source : `Table Ciqual 2025_FR_2025_11_03.xlsx` ;
- SHA-256 du fichier source : `5555c572fa3735991298d832d0427788fa69a11b4fd20a5d580d58942369fbb0` ;
- licence : Licence Ouverte 2.0 (Etalab).

L’extrait conserve le code et le libellé de l’aliment, ses groupes, la valeur brute des
glucides pour 100 g, sa valeur numérique exploitable et son qualificatif. Les autres
constituants nutritionnels ne sont pas copiés.
